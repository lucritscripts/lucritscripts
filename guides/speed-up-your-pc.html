Make an old Windows PC feel fast again

Windows · 7 min read

Ranked by how much you'll actually notice. Do them in order and stop when it feels fine.

1. Swap the hard drive for an SSD

Nothing else comes close. A spinning disk is the bottleneck on essentially every slow machine from before ~2018. Boot times drop from ninety seconds to twelve. Check Task Manager → Performance → Disk; if it says HDD, this is your fix.

2. Cut the startup list

Task Manager → Startup apps. Disable everything that isn't your antivirus or a driver utility. Updaters, launchers, and cloud sync clients can all start on demand.

3. Check what's actually eating RAM

8 GB is the practical floor now. If you sit at 90% memory use with a browser open, more RAM beats any software tweak. Chrome tabs and Electron apps are usually the culprits.

4. Clean out heat, not files

A dust-clogged laptop throttles its CPU to a fraction of rated speed. Compressed air through the fan intake takes five minutes and often recovers more performance than any setting.

Placebo, mostly: registry cleaners, "RAM boosters", defragging an SSD (actively harmful), and disabling visual effects on anything with a real GPU. None of these produce a measurable change.

The checklist

  1. Confirm drive type — Get-PhysicalDisk | Select FriendlyName, MediaType
  2. List startup impact — Get-CimInstance Win32_StartupCommand | Select Name, Command
  3. Check memory pressure — Get-Counter '\Memory\Available MBytes'
  4. Verify thermal throttling — HWiNFO64, watch CPU Package temperature under load.

5. Reinstall, last resort

Settings → System → Recovery → Reset this PC. Keeps your files, wipes the accumulated cruft. Budget an afternoon for reinstalling software.
